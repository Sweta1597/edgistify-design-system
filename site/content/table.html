Table

The dashboard has 45 tables, eleven different header treatments, and two sticky headers. Row hover appears exactly once. Those aren’t styling inconsistencies — they’re usability defects, so this component makes the right thing the default and the exception opt-in.

Sticky by default

A 200-row order list whose header scrolls away makes every column a guess. Scroll inside the box — the head stays, the footer totals stay, and the SKU column keeps its identity. Pass staticHead for the rare table short enough not to need it.

RULE 08

Sorting is drawn from aria-sort, not from a separate prop. The arrow and the announced state come from one value, so a screen reader and a sighted user can never be told different things about the same column.

None of the dashboard’s 45 tables can be sorted today. Click a header above — that is the whole API: pass onSort and the header becomes a real button.

Cell roles

A cell says what kind of thing it holds; the system decides how that looks. The dashboard already reaches for font-mono on 13 SKU cells by instinct — this makes it a decision the system made once.

<Td id>
SKU, order number, bin, pincode. Mono with a slashed zero, so 0 and O can never be confused against a printed label.
<Td num>
Right-aligned and tabular. A column of quantities you cannot compare by eye is a column you read twice.
<Td strong>
The one column carrying the row’s meaning.
<Td muted>
Secondary detail — timestamps, source, notes.
<Td top>
Top-aligned for cells whose neighbours wrap.
<Td actions>
Shrinks to content, sticks right, stops the row click.

API

import { Table, TableWrap, THead, TBody, Tr, Th, Td }
  from '@edgistify/design-system/react/Table';
import '@edgistify/design-system/table.css';

<TableWrap maxHeight={340}>
  <Table density="compact" clickable>
    <THead><Tr>
      <Th sort={dir} onSort={() => sortBy('sku')}>SKU</Th>
      <Th num>Qty</Th>
      <Th actions></Th>
    </Tr></THead>
    <TBody>
      <Tr severity="danger" onClick={open}>
        <Td id>SKU-4417-BLK-M</Td>   // mono, slashed zero
        <Td num>1,240</Td>            // right, tabular
        <Td actions>…</Td>
      </Tr>
    </TBody>
  </Table>
</TableWrap>
