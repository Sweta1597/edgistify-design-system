RULE 09

<Field> owns the id. It generates one, points the label at it, wires aria-describedby to the hint and the error, and sets aria-invalid when an error is present. Getting the association right costs nothing; getting it wrong is no longer possible.

The error styling is driven by aria-invalid rather than a separate class, so what a screen reader announces and what the border shows come from one value — the same rule as aria-sort on Table.

Contrast now covers 177 pairings. Three failed on the first run: the invalid border was unreadable on a dark surface (2.20:1) — the same mistake I made on card accents — and disabled field text sat at 1.97:1.

WCAG exempts inactive controls from contrast, but a locked settings field whose value you cannot read is useless, so disabled fields keep a readable value and take their cue from the fill, the border and the cursor instead.
