RULE 02

Every identifier gets .ed-id. That carries slashed-zero and tabular-nums. A picker holding a carton has to match what is on the screen to what is printed on the label, and a zero that looks like a letter O costs a mis-pick — which costs a return.

Identifiers are a role, not a styling choice made per component. The dashboard already reaches for font-mono 72 times; this just makes it a decision the system made once.

The scale

Eleven steps, which is more than usual — deliberately. The old scale jumped 10px straight to 14px, so developers reached past it: 1,076 arbitrary sizes in the dashboard alone, across 15 values including half-pixels. This one is fine-grained where these products actually live (highlighted) and coarse above it.

--ed-text-2xs10px Dense table meta, row counters
--ed-text-xs11px Secondary cell text, chip labels
--ed-text-sm12px Table cell default, form labels — the workhorse
--ed-text-md13px Body inside dense panels
--ed-text-base14px Default body, button labels
--ed-text-lg16px Intro text, mobile body
--ed-text-xl18px Card titles
--ed-text-2xl20px Section headings
--ed-text-3xl24px Page titles
--ed-text-4xl30px KPI figures
--ed-text-5xl40px Hero metric, scan counters

85% of the 1,518 type declarations across the three apps land on one of these exactly. The rest are half-pixel roundings.
